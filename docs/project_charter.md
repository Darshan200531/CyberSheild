# CyberShield Mini SIEM Threat Detection Portal

## Problem statement
Security-relevant records are generated by different systems and services. Reviewing these records separately can make suspicious activity difficult to identify. This project aims to provide a small educational portal that accepts supported sample logs, converts records into a common event format, applies configurable detection rules and presents alerts.

## Objectives
- Accept sample Linux authentication, Windows Security and Apache web logs.
- Validate and parse supported CSV, JSON and text log formats.
- Normalize records into a common event structure.
- Detect selected suspicious patterns using explainable rules.
- Assign severity/risk scores and store alerts.
- Present events and alerts in a Flask dashboard.

## Scope
The initial implementation is for controlled educational testing with sample or explicitly authorized logs. It is not a replacement for a production SIEM and does not automatically block hosts.

## Technology stack
Python, Flask, SQLite, HTML, CSS, JavaScript, CSV and JSON.

## Limitations
Detection quality depends on log quality and configured rules. Sample data may not represent every operating-system version or deployment. Machine-learning features are future work and must be evaluated for false positives.
